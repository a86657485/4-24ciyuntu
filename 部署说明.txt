  词云图大冒险 - 部署说明
  第4课《抽取文本汇词云》教学游戏应用
═══════════════════════════════════════════════════════

【一、本地一键部署】

  1. 双击 "启动.bat" 即可自动安装依赖并启动服务

  2. 首次运行会提示输入 DeepSeek API Key
     获取地址：https://platform.deepseek.com/api_keys

  3. 启动后访问：
     学习应用：http://localhost:3001
     数据大屏：http://localhost:3001/admin

  4. 局域网内其他设备通过本机 IP 访问，如：
     http://10.9.129.17:3001

  5. 按 Ctrl+C 停止服务


【二、手动部署】

  前提：已安装 Node.js (https://nodejs.org)

  # 1. 创建环境配置
  copy .env.example .env.local
  编辑 .env.local，填入：
    DEEPSEEK_API_KEY="你的API Key"
    GEMINI_API_KEY="你的API Key"
    APP_URL="http://localhost:3001"

  # 2. 安装依赖
  npm install

  # 3. 启动开发服务器
  npm run dev


【三、部署到 Netlify（云端访问）】

  前提：已安装 Netlify CLI

  # 1. 设置环境变量
  npx netlify env:set DEEPSEEK_API_KEY "你的Key"
  npx netlify env:set GEMINI_API_KEY "你的Key"

  # 2. 构建并部署
  npx netlify deploy --prod --dir=dist --functions=netlify/functions

  # 3. 部署后访问
  https://4-24ciyuntu.netlify.app


【四、技术栈】

  前端：React 19 + TypeScript + Vite + Tailwind CSS + Motion
  后端（本机）：Express + SQLite + tsx
  后端（云端）：Netlify Functions + Netlify Blobs
  AI：DeepSeek Chat API


【五、项目结构】

  src/                     # React 前端源码
    stages/                # 8个关卡组件
    components/            # 通用组件（AI助手等）
  server.ts                # Express 后端（含数据大屏）
  netlify/functions/       # Netlify Serverless Functions
  public/admin/            # 静态数据大屏页面
  启动.bat                 # Windows 一键启动脚本


【六、常见问题】

  Q: 端口被占用？
  A: 修改 server.ts 中 PORT 环境变量，或关闭占用进程

  Q: 局域网其他设备无法访问？
  A: 检查 Windows 防火墙是否放行 3001 端口

  Q: AI 助教无响应？
  A: 检查 DEEPSEEK_API_KEY 是否正确配置
